# Yoyo & Kiwi 的英语王国 🩷💙

给姐姐 Yoyo 和弟弟 Kiwi 定制的英语单词学习 App（PWA），无需 App Store，iPhone Safari 添加到主屏幕即可像原生 App 一样使用。

## 功能

- **457 词四级梯度**：🌱 萌芽（启蒙 70 词）→ ⭐ Starters（剑桥 Pre-A1，72 词）→ 🚀 Movers（剑桥 A1，**Power Up 2 全量对齐 239 词**，按 Welcome + Unit 1~9 + 拓展的课本单元学习，可跨级引用）→ 🏆 Flyers（剑桥 A2，76 词），Movers 和 Flyers 每词配例句朗读
- **毕业升级机制**：掌握本级 80% 单词解锁"毕业挑战"（12 题答对 10 题），通过后发毕业帽 🎓、奖励 ⭐×20、自动升入下一级，Flyers 毕业成为"单词大王 👑"
- **听说读写四技能**（姐姐版）：👂 听音选词 · 🎙️ **跟读**（语音识别自动打分，不支持时自评）· 🧩 **组句子**（乱序词块拼回例句）· ✍️ **拼一拼**（字母块拼写，对标 Movers 拼写题）；拼一拼/组句子**答错会重做同一题**（先看正确答案再重拼），不直接跳走
- **可调朗读语速**：首页"🔊 读得多快"一键切慢/适中/快（全局生效、自动保存），语速越慢自动切题的停顿越长
- **无字自主学习**（弟弟版）：🖼️ 看图学（超大图卡 + 英文中文连读 + ▶️ 自动连播磨耳朵）· 👂 **听音点图**（题目全靠听、答案全靠点图、对错全靠语音反馈，不识字也能自己玩）
- **🌍 我的世界**（仅姐姐）：把"做题"变成"给我的世界加东西"。三种加贴纸方式——**➕ 加一个**（听音找图解锁，复用 SRS 答对）、**📖 贴纸库**（她学过的词都在库里，学得越多能选的越多，点一个直接摆）、**🎧 听指令布置房间**（听 "Put the X next to the Y"，从库里把对的东西拖到场景里目标贴纸旁，放对了表扬 + ⭐×2）；贴纸可自由拖动/放大/缩小/删除，全程自动保存；顶部可横滑切换 **8 种环境**（草原/沙漠/大海/小河/森林/雪地/黄昏/太空，全部纯 CSS 画）
- **📕 错题本**：答错的词自动收录、按错误次数排序，可专项翻卡和闯关，练到掌握（3 级盒子）自动移出
- **学习存档**：翻卡片自动记住学到第几张（下次接着学）、学过的词有"学过"计数；所有进度实时保存在本机，另支持**备份码导出/恢复**（换手机、清缓存都不怕丢）
- **姐弟双账号**：打开先选人，Yoyo 粉色主题 🎀 / Kiwi 蓝色主题 🦖，星星、进度和毕业记录各自独立
- **学一学**：翻卡片 + 点卡片听英文发音（iOS 原生语音，无需联网下载），Movers 级朗读单词+例句
- **考一考**：每关 8 题，三种题型（英选中 / 中选英 / 听音选词），干扰项取自同级词库
- **智能闯关**：Leitner 间隔重复算法，优先复习快忘记的词
- **星星奖励**：答对得星、连击加倍，进度保存在手机本地

## 在电脑上运行

```bash
cd yoyo-words
python3 serve.py        # 不缓存服务器，改了代码刷新就能看到新版
# 浏览器打开 http://localhost:8377
```

> 用 `serve.py`（而不是 `python3 -m http.server`）很重要：它给每个文件都加了
> no-cache 头，浏览器每次都拿最新代码，彻底避免"改了功能刷新看不到"。

## 更新加载不出来？强制更新

代码更新后如果 iPhone / 浏览器还是旧版（Service Worker 缓存卡住）：

- App 内在**选人页**点 **🔄 更新到最新版（清缓存）**——会注销 Service Worker、
  清空所有缓存并硬刷新，**不会动学习进度**（星星、错题、我的世界都保留）；
- 选人页底部有**版本号**（如 `版本 v15`），可确认是否已更新到最新；
- 正常情况下 App 每次打开会自动检测新版并秒切，一般不需要手动点。

## 在 iPhone 上使用

1. Mac 上启动服务器：`python3 serve.py`，确保 iPhone 和 Mac 连**同一个 Wi-Fi**；
2. iPhone Safari 打开 `http://<Mac的IP>:8377`（IP 可在 Mac 的
   系统设置 → Wi-Fi → 详细信息 里看，例如 `http://192.168.1.155:8377`）；
3. 点 Safari 底部**分享按钮 → 添加到主屏幕**；
4. 主屏幕上会出现粉色悠悠球图标「英语王国」，点开即全屏使用。

> 注意：这种方式使用时 Mac 需要开着服务器。如果想让 App 完全独立、离线可用，
> 可以把这个文件夹发布到任意免费静态托管（如 GitHub Pages / Cloudflare Pages），
> HTTPS 下 Service Worker 会自动缓存全部资源，之后断网也能用。

## 项目结构

```
index.html            应用入口
manifest.webmanifest  PWA 清单（名称/图标/全屏模式）
sw.js                 Service Worker 离线缓存
css/style.css         儿童友好的卡通风格样式 + 悠悠球动画
js/words.js           分级单词库 + Power Up 2 课本单元
js/engine.js          出题 / 判分 / 间隔重复 / 奖励（纯函数）
js/storage.js         localStorage 进度存储（容错降级）
js/app.js             界面与交互
tests/                node:test 单元测试
docs/REQUIREMENTS.md  需求分析文档
icons/                粉色悠悠球图标（180/192/512）
```
