# 待确认独立性的复核批次

这里的批次**不会被构建器或覆盖审计读取**，不进入正式词库。

| 批次 | 作者 | 复核者 | 原因 |
|---|---|---|---|
| `adult-a-003.json` | `root` | `review_a003` | 复核者由作者 `root` 派生 |
| `adult-b-005.json` | `root` | `review_b005` | 复核者由作者 `root` 派生 |
| `adult-c-007.json` | `root` | `/root/review_c007` | 复核者由作者 `root` 派生 |
| `adult-c-008.json` | `root` | `/root/review_c007` | 复核者由作者 `root` 派生，且沿用 C007 的复核者名 |

构建器的独立性检查只比较作者与复核者的名字字符串，上述名字字面不同，因此能通过检查；
但按本项目的规则，作者派生的子代理不算与作者相互独立，所以暂不合入。

逐词复核意见具体、互不重复，内容本身保留完好。处理方式二选一：

- 由 `vocab_author_a/b/c` 等与 `root` 不同的作者重新复核后，把新文件放入 `vocab-reviewed/`；
- 或由项目负责人确认接受这种复核方式后，把本目录文件直接移回 `vocab-reviewed/` 并重新构建。
