# 家庭英语学习 —— 需求分析文档

## 1. 项目背景

为 Yoyo、Kiwi 和森蝶制作一个共用但学习路线独立的英语 App，在 iPhone 上使用。
产品形态选择 **PWA（渐进式网页应用）**：

- 无需 Apple 开发者账号 / App Store 审核；
- Safari 打开后「添加到主屏幕」，图标、启动全屏体验与原生 App 一致；
- 纯前端实现，数据存在手机本地（localStorage），无需后端、无隐私风险。

## 2. 用户画像

| 角色 | 描述 | 诉求 |
|------|------|------|
| Yoyo（核心用户） | 学龄前/小学低年级孩子 | 好玩、有奖励、觉得"这是我的 App" |
| Kiwi（启蒙用户） | 尚未识字的幼儿 | 不依赖文字，靠声音、图片和动作自主学习 |
| 森蝶（成人用户） | CET4 起点，逐步扩展到 CET6、考研及生活高频词汇 | 先系统背词，再通过小测和间隔复习巩固 |
| 家长 | 安装、陪学、维护 | 内容靠谱、无广告、能看到学习进度 |

## 3. 功能需求

### 3.1 单词库（P0）
- 内置 8 个主题分类：动物、水果食物、颜色、数字、身体、家庭、学校、大自然；
- 共 70+ 个常用启蒙单词，每个单词包含：英文、中文、表情图（emoji 大图）、分类；
- 数据完整性有单元测试保障（无重复、字段齐全、每类不少于 6 个词）。

### 3.2 学一学 —— 卡片学习模式（P0）
- 大卡片展示：emoji 图 + 英文 + 中文；
- 点卡片播放英文发音（iOS Safari 内置语音合成，离线可用）；
- 左右切换，进度提示。

### 3.3 考一考 —— 闯关测验模式（P0）
- 每关 8 题，三种题型混合：看英文选中文、看中文选英文、听音选词；
- 4 个选项，干扰项优先取同分类单词（更有挑战性）；
- 答对加星星、有连击奖励；答错立即显示正确答案（绿色高亮）；
- 关卡结束展示成绩页：星星数、正确率、鼓励语（"Yoyo 你真棒！"）。

### 3.4 记忆算法（P0）
- 简化版 Leitner 间隔重复：每个单词有 0~5 级"熟练盒子"；
- 答对升一级，答错回到 1 级；按 [0,1,2,4,7,15] 天间隔安排复习；
- 盒子 ≥ 3 级视为"已掌握"；
- 测验优先出"到期该复习"的词。

### 3.5 成长激励（P0）
- 星星总数展示在首页（"Yoyo 收集的星星"）；
- 已掌握单词数进度条；
- 答题连击有额外星星加成。

### 3.6 Yoyo 专属元素（P0，产品灵魂）
- App 名称：**Yoyo & Kiwi 的英语王国**；
- 首页问候："Hi, Yoyo! 👋 欢迎回到你的英语王国"；
- 吉祥物：一只会上下弹跳的悠悠球（yo-yo）动画，呼应 Yoyo 的名字；
- 「Yoyo 专属」徽章；成绩页专属鼓励语；
- 主屏幕图标是一颗粉色悠悠球。

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 平台 | iPhone Safari（兼容 iOS 15+），也可在电脑浏览器使用 |
| 离线 | Service Worker 缓存应用外壳，localhost/HTTPS 下支持离线 |
| 数据 | 学习进度存 localStorage，仅存本机，不上传 |
| 性能 | 纯静态资源、零第三方依赖，首屏 < 1s |
| 无障碍/儿童友好 | 大字号、大按钮（≥ 64px 触控区）、高对比配色、圆角卡通风 |
| 适配 | 竖屏优先，支持 iPhone 刘海屏 safe-area |

## 5. 技术方案

- 纯 HTML/CSS/JavaScript（ES Modules），零构建、零依赖；
- 核心逻辑（出题、判分、间隔重复、存储）与 UI 分离成纯函数模块，便于单元测试；
- 单元测试使用 Node.js 内置 `node:test`；
- 本地运行：`python3 serve.py`；需要同 Wi-Fi 访问时显式使用 `--host 0.0.0.0`。

## 6. v2 需求：分级词库 + 姐弟双账号

背景：姐姐 Yoyo 已达剑桥 Movers 水平（在学 Power Up 2），启蒙词过于简单；
弟弟 Kiwi（档案 id 仍为 yodi）刚起步。App 需要有梯度，姐弟共用但互不干扰。

### 6.1 三级词库
| 级别 | 对标 | 词量 | 特性 |
|------|------|------|------|
| 🌱 萌芽 | 启蒙 | 70 | emoji 大图 + 中英文（适合 Kiwi） |
| ⭐ Starters | 剑桥 Pre-A1 | 72 | 新增服装/家居/玩具运动/交通/动作分类 |
| 🚀 Movers | 剑桥 A1（Power Up 2） | 78 | **每词配例句**，朗读单词+例句；新增地点/天气/形容词/时间/人物分类 |

- 测验干扰项取自同级别词库，保证难度匹配；
- 中文释义同级别内不重复（避免选项撞车），英文全局不重复。

### 6.2 姐弟双账号
- 启动先选人："今天谁来学习呀？"；
- Yoyo 🎀 粉色主题、默认 Movers；Kiwi 🦖 蓝色主题、默认萌芽；
- 星星、进度、当前级别每人独立存储，v1 旧数据自动迁移给 Yoyo；
- 级别可随时切换（首页分段控件），进度按级别统计。

## 7. v3 需求：四级梯度 + 词汇通关机制

背景：Movers 78 词对姐姐不够用（官方 Movers 词表约 550 词），且缺少
"学完这级怎么上下一级"的通道。

### 7.1 词库扩容（共 322 词）
| 级别 | 词量 | 变化 |
|------|------|------|
| 🌱 萌芽 | 70 | 不变 |
| ⭐ Starters | 72 | 不变 |
| 🚀 Movers | 104 | +26：学校（词典/作业/操场…）、自然（岛/湖/山/森林…）、服装（大衣/围巾/头盔…）、交通（电车/拖拉机/卡车…） |
| 🏆 Flyers（新增） | 76 | 剑桥 A2 代表词：动物、地点、职业、太空、餐具食物、物品、形容词、爱好，全部带例句 |

### 7.2 词汇通关机制（学习闭环）
1. **积累期**：首页显示"🎓 词汇通关挑战 · 再掌握 N 个单词解锁"+ 金色进度条；
2. **解锁**：掌握本级 ≥ 80% 单词后，出现金色"词汇通关挑战"按钮；
3. **挑战**：12 道本级随机题，答对 ≥ 10 题通过；
4. **通关**：发毕业帽 🎓（级别芯片上常驻）、奖励 ⭐×20、自动进入下一词汇级别；
   未通过则鼓励再战，不扣任何东西；
5. **通关**：Flyers 毕业后获得"单词大王 👑"称号。

这只表示应用内核心词汇掌握，不等同于 Cambridge 真实等级考试通过。级别仍可自由切换，通关记录按人独立保存。

## 8. v4 需求：错题本 + 学习存档 + Power Up 2 全量对齐

1. **错题本**：答错的词自动进错题本（按错误次数排序），支持专项翻卡和闯关；
   专项训练的中间答对不重复发星，练到掌握（3 级盒子）自动移出时一次性奖励 3 星。
   成人路线不发儿童星星。数据从已有答题记录派生，无需额外存储。
2. **学习存档**：翻卡片自动记录位置（下次继续/可从头重学）、学过的词打"学过"标记；
   全部进度实时存 localStorage；新增备份码导出/恢复（base64，跨设备迁移）。
3. **PU2 全量对齐**：Movers 级按 Power Up 2 官方词表重构为课本单元学习
   （Welcome + Unit 1~9，新增 135 词/短语，全部带例句）；单元可跨级引用已有
   单词（如 U5 的 run/lion 来自低级别、U9 的 bored 来自 Flyers）；不在课本内的
   原 Movers 词自动归入"🧩 拓展"单元，保证每个词都有学习入口。
   cook（厨师/做饭）、fly（苍蝇/飞）按不同词义分别收录，题目用例句语境消歧，
   同拼写词不会互相成为干扰项。

## 9. v5 需求：听说读写四技能 + 弟弟无字自主学习

### 9.1 姐姐版四技能（对标优秀英语 App）
| 技能 | 模块 | 玩法 | 奖励 |
|------|------|------|------|
| 听 | 🎯 考一考 | 听音选词（已有） | ⭐×1 |
| 说 | 🎙️ 跟读 | 听示范→对麦克风朗读，语音识别打分（词覆盖率 ≥70% 过关）；设备不支持时降级为"听读自评" | ⭐×2 |
| 读 | 🧩 组句子 | 例句拆成乱序词块，点词块拼回原句（限 3~9 词的例句） | ⭐×2 |
| 写 | ✍️ 拼一拼 | 看图听音，用乱序字母块拼出单词（限纯字母 3~10 位，对标 Movers 拼写题） | ⭐×1 |

拼一拼/组句子的对错同样进入间隔重复记忆和错题本。

### 9.2 弟弟版无字模式（preReader）
核心原则：**看图 + 听声，全程零识字依赖**。
- 独立的 24 项家庭高频听说内容，分为身体动作、家人问候、吃喝需要、玩具指令
  四组，不展示 Starters / Movers 等考试级别；
- 每日只引入 2 项新内容，并搭配最多 4 项已学复习；首日还没有旧内容时，6 道题
  只围绕这 2 项重复，不额外塞新词；
- 🖼️ 看图学：初见朗读“英文 → 中文 → 英文”，正确两次后撤掉中文支架，只留英文；
- 👂 听音点图：播放英文，点 4 张大图之一；选项图两两不同（引擎保证同图词
  不会同屏）；答对语音夸"真棒"，答错语音报正确答案——对错靠听不靠看；
- 名词之外加入 “Jump!”, “Clap your hands!”, “More, please.”, “Give it to me.”
  等动作指令和完整口语块，让 Kiwi 能听懂、执行并表达需要；
- 导航按钮用 ⬅️ ➡️ 图标代替文字。

### 9.3 Yoyo 从单词到表达（第一批）
- 保持 Power Up 2 / Movers 词汇为主线，英音统一使用 `en-GB`；
- Unit 1 新增 Nature Explorer 三步任务：高频句型输入 → 四轮情境对话 →
  看自然图片或窗外自主说 3–4 句话；
- 完成状态进入 Yoyo 档案的 `missions` 字段，自动存档并随备份码迁移；
- “词汇通关”不冒充 Movers / Flyers 真实考试能力，后续单元继续补听说读写综合任务。

## 10. v6 需求：「我的世界」贴纸场景（仅姐姐 Yoyo，第一版）

定位：把"复习一个单词"从"做一道题"改成"往我自己的场景里加一个东西"。
SRS 引擎不动，后台照常决定今天碰哪些词，只换表层。不动弟弟。

**Story 1 — 听音找它，解锁贴纸**：点"➕ 加一个"，飘出 3 张图，语音
"Where is the cat?"，点对 → 变贴纸飞进场景；点错无惩罚，图晃一下重试。
第一次点对 = 触发一次现有 SRS "答对"（`gradeAnswer`）；出哪个词由 `dueWords` 决定；
干扰项复用 `pickPicDistractors`（1 对 + 2 干扰，共 3 图）。

**Story 2 — 摆进场景**：贴纸可自由拖动、放大、缩小、删除，无对错无打分。
拖动跟手、落下有轻微反馈；选中出工具条（大/小/删除）；点已摆的贴纸再读一遍英文。

**Story 3 — 自动存**：每次改动自动存（无保存按钮），进 Yoyo 档案新增 `world`
字段（现已迁移为按场景隔离的 `worlds`），备份码一起编码。

技术：贴纸素材直接用 `words.js` 每个词的 emoji（贴纸 id = word id，不补图）；
背景纯 CSS（蓝天 + 方块草地，无图片资源）；拖拽用原生 Pointer 事件，不引第三方库。

本期不做（故意砍）：多场景/作品册、导图片、捏怪物换装、贴纸动画、新奖励体系。
唯一要看的信号：连续几天没新东西可解锁时，她还会主动打开回去摆吗？

## 11. v7 需求：拼一拼/组句子答错重做 + 可调朗读语速 + 放慢切换节奏

1. **答错重做**：拼一拼、组句子答错时不再"显示答案 + 直接跳下一个"，改为
   露出正确拼法/句子当提示、读一遍，稍后**重做同一个词/句**（不推进），直到做对
   才进入下一个。答错仍记一次 SRS（进错题本），但不计入本轮"完成数"。
2. **可调语速**：新增全局 `speechRate`（慢 0.6 / 适中 0.8 / 快 1.0），首页一行
   "🔊 读得多快"随时切换，立即生效并保存；备份码带上。所有朗读走此语速。
3. **放慢切换**：所有"读完自动进入下一题"的停顿改用 `gap(base)`，语速越慢停顿越长，
   避免语音没读完就切走。

## 12. v19 需求：自然英音与音色选择

1. 自动读取设备可用音色，优先选择 `en-GB`，并优先增强、高质量或常见英式声音；
   家长可以在首页试听并固定具体音色，设备不支持时回退系统默认。
2. “慢读”不再把 Web Speech 机械拉到 0.6 倍，而是映射为保留重音、连读和语调的
   自然慢速；孤立单词比句子略慢，便于孩子听清音素。
3. 单词与例句、中英文切换、对话相邻句之间加入短暂停顿；换页立即停止旧朗读，
   避免不同页面的声音重叠。
4. `speechVoice` 与语速一起进入本地存档和备份码；语音模块加入 Service Worker
   离线缓存。未来可在不改学习逻辑的前提下增加预生成神经语音 MP3。

## 12. v8 需求：贴纸和学习关联 + 听指令布置房间（可玩性）

背景：① 希望"我的世界"的贴纸跟学习过程有关联——她学得多的，能主动去挑；
② 提升可玩性，把测试包装成过家家式的"布置房间"游戏。

1. **贴纸库（📖）**：世界页新增"贴纸库"，列出她**学过的词**（翻过卡片 seen，
   或已摆进世界的）。学得越多，库越丰富；点一个直接放进场景。听音解锁成功时
   也标记为"学过"，让库随游玩自然生长。
2. **听指令布置房间（🎧，进阶思路 4）**：把词汇测试变成情境游戏。
   - 从场景现有贴纸挑一个当参照物 Y，从学过的词挑要放的 X + 2 个干扰，
     语音 + 文字给出 "Put the X next to the Y"（把 X 放到 Y 旁边）；
   - 她从底部托盘把**对的图**拖进场景、放到目标 Y 旁边（目标贴纸脉冲高亮辅助定位）；
   - 判定：拖对图 + 落点靠近目标（`isNear`，百分比距离阈值）→ 表扬 + ⭐×2，
     X 留在场景丰富房间；拖错图或没放对位置 → 温柔提示重试，不惩罚；
   - 一轮 3 题，每题基于当前场景实时生成。
   - 简化（第一版）：介词统一用 "next to"（判定=靠近，名实相符，也教 Movers 介词）；
     需要场景先有 ≥1 个贴纸、且学过 ≥2 个词，否则引导先去摆/去学；
     跨容器拖拽用原生 Pointer 事件（浮层跟手 + 落点判定），不引第三方库。

## 13. v9 需求：我的世界多环境背景

背景：原来只有一个"蓝天草地"，太单调。希望有更多可切换的环境。

- 新增 **8 种环境**（草原/沙漠/大海/小河/森林/雪地/黄昏/太空），全部**纯 CSS 画**
  （渐变 + 伪元素做太阳/星星/沙丘/海浪/河流等），不加任何图片资源；
- 世界页通过大卡片选择环境；每个环境维护独立贴纸数组，切换背景不会携带其他场景的小动物；
- 当前环境存 Yoyo 档案的 `worldScene` 字段，各场景贴纸存入 `worlds`，备份码全部带上；听指令布置房间沿用当前环境；
- 贴纸层 `z-index` 抬到背景纹理之上，低处贴纸不会被沙丘/海浪盖住。

## 14. v10 需求：我的世界单词不重复 + 取词来自"学过的词"

1. **不重复**：同一个单词在**同一场景**里最多一个。贴纸库/听音解锁/听指令都只从
   "学过且还没摆进当前场景"的词里出；进入场景时顺手去掉历史重复。
2. **取词来自学习**：可加进世界的词 = 她**学过的词**（智能闯关做过题 progress
   或翻过卡 seen），而不是陌生新词。学过的都摆完了 → 引导"🚀 去智能闯关"再学几个。
3. **场景选择更直观**：世界页标题下放一个显眼的"🖼️ 换背景（现在：xx）"大按钮，
   点开是 8 种环境的**九宫格**，每张卡片带该环境的**真实迷你预览图**（复用 .scene--<id>），
   点一张就选中并返回（取代原来不好发现的横滑条）。

## 15. v11 需求：解决浏览器缓存导致更新加载不出来

问题：改了代码，iPhone/浏览器仍显示旧版（HTTP 缓存 + 旧 Service Worker 卡住）。

三层修复：
1. **不缓存本地服务器 `serve.py`**：每个文件加 `Cache-Control: no-cache, no-store,
   must-revalidate` 头，浏览器每次拿最新代码（取代 `python3 -m http.server`）。
2. **Service Worker 自动更新**：注册加 `updateViaCache:'none'`（检查 sw.js 绕过 HTTP
   缓存）+ 启动即 `reg.update()`；install 里 `skipWaiting`、activate 里 `clients.claim`
   并删旧缓存；新 SW 接管触发 `controllerchange` → 自动刷新一次（仅更新时，不在首装时）。
3. **手动兜底**：选人页"🔄 更新到最新版（清缓存）"按钮，注销所有 SW + 清空所有
   CacheStorage + 带时间戳硬刷新；**只清缓存，不动 localStorage**（进度全保留）。
   选人页显示版本号（APP_VERSION，跟 sw.js 的 CACHE 一起改）以便确认。

## 17. v21 需求：错题出本奖励、场景隔离与近期词避让

1. **错题奖励闭环**：儿童在错题专项训练里，未达到掌握线的答对不加星；某词从
   2 级升到 3 级并自动移出错题本时，只奖励一次 ⭐×3，之后即使再次遗忘也不重复刷毕业奖。
   跟读、拼写、组句等其他入口不作为错题清除奖励入口，避免通过撤销或重复结算刷星。
   森蝶的错词只更新 SRS，始终不加星。
2. **八场景独立世界**：`worlds[sceneId]` 分别保存草原、沙漠、大海、小河、森林、雪地、
   黄昏和太空的贴纸；旧版单数组 `world` 自动迁入升级时所选场景，旧备份可恢复且不丢进度。

   档案级短期历史，同时保留通道级窗口；记录会进入存档，跨入口、刷新后仍能避让。SRS 仍负责
   到期排序，词池足够时优先后移刚出现过的词，小词池不足时自动回填，不减少题数。
4. **听指令奖励去重**：同一词首次成功放入任意场景奖励 ⭐×2；之后可继续练习和在其他场景
